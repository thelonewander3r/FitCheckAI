=== 6. src/lib/wardrobe/composer.ts (new) ===
Pure TypeScript composition engine (no IO):
export interface ComposeContext { formality: WardrobeFormality; palette?: string[]; season?: string; presentation?: string }
export interface ComposedOutfit { id: string; items: WardrobeItem[]; score: number; why: string[] }
export interface ComposeResult { outfits: ComposedOutfit[]; gaps: string[] }
export function composeOutfits(items: WardrobeItem[], ctx: ComposeContext): ComposeResult
Rules:
- A valid outfit is: one dress, OR at least one top + one bottom, optionally plus outerwear and/or shoes/accessories.
- Formality gating: each included piece must have formality level >= ctx.formality OR exactly one step below (a lower-formality top is acceptable only if the outfit includes a jacket/outerwear at the required level). Implement a small level index (casual=0 ... formal=4).
- Season: pieces whose seasons include ctx.season or "any" are preferred (+2); others are allowed but penalized (-2).
- Color harmony: count non-neutral colors (not in [black, white, navy, charcoal, gray, cream, beige, camel]). Two or more distinct non-neutral colors: -3 each beyond the first. A piece whose color is in ctx.palette (lowercased): +3.
- Presentation: if ctx.presentation is "feminine", prefer dresses and tops (category tops/dresses get +1); if "masculine", prefer tops+bottoms combos (+1 to bottoms); neutral no bonus.
- Generate combos: for each dress candidate + for each (top, bottom) pair, add outerwear (best formality match) and shoes (any) if available. Cap exploration reasonably (first 60 items sorted by formality desc then color harmony).
- Score = base 50 + formality gating satisfied (+10 when all pieces at required level) + color bonuses + season + presentation. Return top 3 outfits sorted by score desc, each with why strings (e.g. "Blazer matches business-professional.", "Navy top flatters the recommended palette.").
- gaps: categories missing at the required formality level (e.g. if no outerwear piece with formality >= required, gap "outerwear at {formality}"). Max 4 gap strings, deduped.
- Outfit ids: "combo-1", "combo-2", "combo-3".
